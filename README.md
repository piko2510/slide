## 公開範囲と確認状況

公開向けに書き直した説明資料のみを置きます。
開発用リポジトリの履歴、内部設定、認証情報、実メール、個人・顧客の情報は含めません。
図や操作例は、明記がない限り説明用です。
構成・実装の存在と、実機動作や費用・品質の改善実績は区別します。

現時点では完成版のPDF・PowerPointは掲載していません。
Copilotでの実際の添付、生成、表示、Meiryo UIの描画は未検証です。
モデル名は利用者指定の表記で、利用機能・契約・性能を保証するものではありません。
フォントファイルは配布・添付・埋め込みしません。
