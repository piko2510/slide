# 発表資料

## わしの家のAI環境

**自宅サーバーとCodexで、AIに仕事を任せる**

社内エンジニア向けの10分発表と、5分の質疑を想定した公開資料です。
現在の台本・構成は**v6（全18枚）**です。
**共通デザインは5.6の基準を継承**し、白背景、Meiryo UI、青と薄灰、角丸・影なしを維持します。
資料の版番号とデザインの基準は別です。

自宅Proxmox上の作業・情報基盤と、クラウドAI、GitHubの全体像を最初に見せます。
AIへ仕事を任せたいのに人間が中継していた負担から、独自ハーネスを作った理由、今度は自作基盤の保守が仕事になったこと、標準へ戻した判断へつなぎます。
後半は、現在のCodex、親と担当、AGENTS.md・Skill・Hookを「自分が毎回つながなくても仕事が進むか」という問いへの対処として説明します。
最初の不具合修正の依頼例へ戻って意味を回収した後、残る事情説明の負担からコンテキスト基盤とJevへ進みます。
最後は、部品がそろったかではなく、本人の中継が減って仕事が進んだかを確かめるという目的へ戻ります。

- [全18枚のスライド設計書・台本](talks/homelab-ai/slide-design.md)：掲載文言、図の意図、話す内容、台本外の技術注記の正本。
- [発表構成](talks/homelab-ai/outline.md)：18枚の順序、話の転換点、説明9分25秒＋余裕35秒の時間配分。
- [制作仕様](talks/homelab-ai/production-spec.md)：5.6を継承する共通スタイル、実装説明と転換ページの配置、PowerPoint生成後の確認項目。
- [Copilot一枚生成セット](talks/homelab-ai/copilot/README.md)：slide-01〜slide-18をv6へ同期済み。3ファイルを添付し、prompt.mdをチャット欄へ貼って1枚ずつ生成します。

## 更新範囲と確認上の注意

台本・構成・制作仕様と、それに同期したCopilot生成セットを管理しています。
**PowerPoint本体は、今回のCopilot入力同期では再生成していません。**
v5以前の13枚・15枚のPPTXを、18枚のv6と混ぜないでください。
10分の配分は制作上の枠であり、読み上げの実測値ではありません。

説明用のMarkdown・JSON・依頼例を、実行用設定や成功実績として扱いません。
構成・規則の記述、過去のつまずき、実運用の受入確認を区別します。
自作の理由を、当時の標準機能が不足していたという未確認の主張へ置き換えません。
Skill Creatorの作成方法と、代表Skillを生成した当時の未確認ログを区別します。
Hook定義の存在だけで、実機での有効化・信頼確認・全経路の通過を主張しません。
Jevの全面稼働や費用削減を、最新の実行根拠なしに主張しません。
公開資料には内部IP、認証情報、実メール、個人情報、顧客情報、生ログを載せません。
