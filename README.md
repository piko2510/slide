## v5の変更

旧08の抽象的な役割説明を、AGENTS.mdの短縮例、Skill Creatorと代表Skillのフォルダ・SKILL.md、Hookの設定と呼出先の三枚に置き換えました。
SkillとHookはgithub-main-refreshの同じPythonを追います。
新しい三枚に合わせて全体の台本と時間配分を調整し、最終受入、Hookの条件付き動作、Jevの設計と実利用の区別を明確にしました。

## 更新範囲と確認上の注意

今回の更新は台本・構成・制作仕様です。
**PowerPoint本体は、この更新では再生成していません。**
既存の13枚PPTXは旧構成であり、15枚のv5と混ぜないでください。
10分の配分は制作上の枠であり、読み上げの実測値ではありません。

説明用のMarkdown・JSON・依頼例を、実行用設定や成功実績として扱いません。
構成・規則の記述、過去のつまずき、実運用の受入確認を区別します。
Skill Creatorの作成方法と、代表Skillを生成した当時の未確認ログを区別します。
Hook定義の存在だけで、実機での有効化・信頼確認・全経路の通過を主張しません。
Jevの全面稼働や費用削減を、最新の実行根拠なしに主張しません。
公開資料には内部IP、認証情報、実メール、個人情報、顧客情報、生ログを載せません。
