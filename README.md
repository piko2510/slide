# 発表資料

## わしの家のAI環境

**自宅サーバーとCodexで、AIに仕事を任せる**

社内エンジニア向けの10分発表と、5分の質疑を想定した公開資料です。
現在の設計は**v4（2026-09-26）**です。

自宅Proxmox上の作業・情報基盤と、クラウドAI、GitHubの全体像を最初に見せます。
人間が事情説明・中継・再開係になっていた負担を説明し、独自ハーネスの撤去は一枚で畳みます。
後半は現在のCodexのモデル・ツール往復、親と担当の分担、確認と差し戻し、コンテキスト基盤、Jevの入力処理を説明します。
最後は、本人がAIの段取り係をしなくてよい環境を作るという目的へ戻ります。

- [全13枚のスライド設計書](talks/homelab-ai/slide-design.md)：掲載文言、図の意図、話す内容、技術注記の正本。
- [発表構成](talks/homelab-ai/outline.md)：13枚の順序と、説明9分25秒＋余裕35秒の時間配分。
- [制作仕様](talks/homelab-ai/production-spec.md)：共通スタイル、配置方針、PowerPoint生成後の確認項目。
- [旧Copilotセットについて](talks/homelab-ai/copilot/README.md)：既存の一枚生成セットはv4へ未同期です。そのまま現行入力に使わないでください。

今回の更新は構成・設計・制作仕様です。
既存のv3 PowerPoint本体は、この更新では再生成していません。

説明用の依頼例を成功実績として扱いません。
構成・規則の記述、過去のつまずき、実運用の受入確認を区別します。
Jevの全面稼働や費用削減を、最新の実行根拠なしに主張しません。
公開資料には内部IP、認証情報、実メール、個人情報、顧客情報、生ログを載せません。
