# Copilot 5.6 Thinkで1枚ずつ生成するセット — 設計判断版

発表 **「AIに任せるために、何を作らないか」** の13枚を、Copilot Chat Basic / 5.6 Thinkで1枚ずつ`.pptx`生成する入力一式です。

## 使い方
対象の `slide-01`〜`slide-13` で次の3ファイルを添付します。

1. `00_style_guide.md`
2. `01_talk_outline.md`
3. `02_slide_brief.md`

同じフォルダの **`prompt.md` の本文をチャット欄へ貼り付けます**。
`prompt.md`自体は添付しません。

## 今回の13枚が追うもの
```text
人間がAIを管理
→ 独自Harnessへ管理を移す
→ Harness自身の管理が増える
→ 独自Harnessを大きく削る
→ 複雑さがルールへ移る
→ 強いモデルへ寄せすぎる問題が出る
→ 判断の種類でモデルを分ける
→ 文脈の前処理へJevを入れる
→ Jevにも選ばせない境界を作る
→ 現在の責務分離へ
```
