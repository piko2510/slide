# Copilot一枚生成セット｜v6・全18枚

slide-01〜slide-18を、現行の18枚構成へ同期しました。
既存のslide-01〜slide-13も中身を置き換えています。
末尾に5枚を追加しただけではありません。
台本・掲載文言・図の意図・技術注記はv6、デザインは5.6の基準です。

## 使い方

作りたいページのslide-NNフォルダを開いてください。
同じフォルダの00_style_guide.md、01_talk_outline.md、02_slide_brief.mdの3ファイルをCopilotへ添付し、prompt.mdの本文をチャット欄へ貼ります。
prompt.mdは4つ目の添付ファイルではありません。
出力はhomelab_ai_NN.pptxの1枚だけで、ページ番号はNN / 18です。
別ページの02_slide_brief.mdや、以前ダウンロードした旧セットを混ぜないでください。

```text
slide-NN/
├── 00_style_guide.md   共通デザイン・配置・出力と検査
├── 01_talk_outline.md 全18枚の流れと時間配分
├── 02_slide_brief.md  対象ページの掲載文言・図・台本・技術注記
└── prompt.md          チャット欄へ貼る、その1枚の生成指示
```

3添付だけで必要な内容がそろいます。
台本を読むために別のslide-design.mdを追加添付したり、GitHubのリンク先を取得したりする必要はありません。
各02_slide_brief.mdの「話す内容」は発表者ノートへ原文のまま収録し、技術注記・出典と区別する指示です。
画面には台本全文を転載しません。

## 更新と生成の区別

今回更新したのはCopilotへ渡すMarkdownの生成セットです。
PPTX本体の生成、レンダリング、通し読み、実機のHookやJevの動作検証は行っていません。
各promptには生成後の検査を指示していますが、入力ファイルの存在を生成成功や検査済みの証拠にはしません。
以前のセットはGit履歴で確認できます。現行ディレクトリはv6用です。
