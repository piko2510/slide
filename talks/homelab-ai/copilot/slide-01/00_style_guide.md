# 共通デザイン仕様 — Markdown詳細版 v2.0

このファイルは制作指示です。指示文・表・確認リスト自体をスライドに載せないでください。

## 1. 成果物と入力の役割

成果物は、編集可能なPowerPoint（`.pptx`）1ファイル、スライド数は必ず1枚です。
生成対象、ファイル名、ページ番号、掲載する文章は `02_slide_brief.md` に従います。
全13枚の目次、別表紙、説明ページ、空白ページ、非表示スライド、発表者ノートを追加しません。
`01_talk_outline.md` は背景理解用であり、全ページの生成指示ではありません。

| 入力 | 決めること | 決めないこと |
| --- | --- | --- |
| チャット欄のプロンプト | 今回生成する1枚と出力条件 | 他ページの生成 |
| `00_style_guide.md` | 共通の寸法・書式・図形・可読性 | 掲載する新たな事実 |
| `01_talk_outline.md` | 発表の目的、用語、説明範囲 | 今回の掲載文章の追加 |
| `02_slide_brief.md` | 確定文言、オブジェクト、座標、接続関係 | 白背景・指定フォント等の解除 |

内容は専用指示書、書式は共通仕様に従います。専用指示書の表紙・結びの配置例外だけを優先します。
禁止条件・否定・未確認の留保を、一般的なデザイン改善のために変更しません。

## 2. キャンバスと共通領域

横長16:9、幅13 1/3インチ、高さ7.5インチ。座標は左上原点、単位はインチです。
`x, y, w, h` は左端、上端、幅、高さを表します。
専用指示書の座標は初期配置です。接続関係と文字サイズを保った小幅な調整はできます。

| 領域 | x | y | w | h | 用途 |
| --- | ---: | ---: | ---: | ---: | --- |
| T：タイトル | 0.60 | 0.35 | 12.10 | 1.05 | 最大2行、32pt |
| B：主図・本文 | 0.60 | 1.70 | 12.10 | 4.25 | この1枚の主役 |
| K：結論 | 0.60 | 6.15 | 12.10 | 0.70 | 最大2行、24pt |
| N：注意書き | 0.60 | 6.91 | 10.80 | 0.45 | 必要な場合だけ、16pt、最大2行 |
| P：ページ番号 | 11.65 | 7.00 | 1.05 | 0.25 | 右揃え、14pt |

通常ページで図をタイトル領域や結論領域へ侵入させません。
タイトルと主図の間には空間を残します。下部の注意書きとページ番号を重ねません。
ページ番号は `01 / 13` の形式です。ファイル内のスライドは1枚でも、発表全体の番号を使います。

## 3. 配色と装飾

| 対象 | 色・指定 |
| --- | --- |
| スライド背景 | 白 `#FFFFFF`、全ページ共通 |
| タイトル・本文 | 濃いグレー `#222222` |
| 注意書き・補助文字 | `#505050` |
| 唯一の強調色 | 青 `#1F5FAF` |
| 枠線 | `#D0D5DD`、1〜1.25pt |
| 補助カード背景 | 白、必要な場合だけ `#F5F6F8` |
| コネクタ | 濃いグレーまたは上記の青、1.5〜2pt |

白い余白を主にし、青は見出し・主経路・重要語に限定します。
写真、装飾イラスト、ロゴ、絵文字、影、グラデーション、立体効果、広い濃色帯、アニメーションは使いません。
意味は文字ラベルと形・線種でも示します。色だけで区別しません。
カードは原則角の四角い長方形です。図形ごとに見た目を変えません。

## 4. Meiryo UIと文字組み

日本語、英数字、括弧、図中ラベル、表、ページ番号のフォント名をすべて **Meiryo UI** に設定します。
テーマの見出し・本文だけでなく、各テキストのラテン文字用・東アジア文字用にも同じ指定を適用します。
Meiryo、游ゴシック、Aptos、Calibriへ勝手に置換しません。
生成環境にMeiryo UIがなくても、ファイルのフォント名は保持します。実フォントで表示を確認できない場合は納品メッセージで未確認とします。
フォントファイルを取得・添付・配布・埋め込みしません。文字を画像や輪郭へ変換して見た目を固定しません。

| 文字 | サイズ | 書式 |
| --- | --- | --- |
| 通常タイトル | 32pt | 太字、原則左揃え、最大2行 |
| 表紙タイトル | 42pt | 太字、専用配置 |
| 表紙サブタイトル | 28pt | 通常、専用配置 |
| 結びの中央メッセージ | 32pt | 太字、指定改行 |
| カード・箱の見出し | 24pt | 太字 |
| 本文・主要な図ラベル | 22pt | 通常、原則左揃え |
| 下部の結論 | 24pt | 必要な重要語のみ太字 |
| 注意書き | 16pt | 補助的内容だけ |
| ページ番号 | 14pt | 右揃え |

本文を22pt未満にして詰め込みません。16ptの注意書きへ主張や説明を移しません。
同じ階層は同じサイズで揃えます。本文の行間はおおむね1.05〜1.15、段落後の余白は控えめにします。
図形内の左右余白は0.16〜0.22インチを目安にします。上下も最低0.10インチを確保します。
カード見出しと本文は別テキストボックスにし、行送りで無理に位置を合わせません。
日本語の句読点を行頭へ出さず、英単語の途中を切らず、意味のまとまりで改行します。
Markdown表の `<br>` は表示上の改行です。文字列 `<br>` をそのまま印字しません。

## 5. 編集可能な図の実装

文字はテキスト、箱は標準図形、線は標準の線・コネクタ、表は編集可能な表で作ります。
スライド全体・主図をPNG、SVG、スクリーンショットとして貼り付ける方法は使いません。
図形をグループ化しても、解除後に文章・箱・線を個別編集できる状態を保ちます。
専用指示書のオブジェクトIDは接続確認用です。IDや座標をスライドへ印字しません。

矢印は指定された接続だけを描きます。順序のない比較カードに矢印を追加しません。
コネクタは箱の境界で接続し、本文を横切らせません。ラベルには余白を取り、線上に文字を重ねません。
往復は両端矢印、条件付きは破線など、専用指示書の線種を守ります。
重なり順は、領域の外枠、コネクタ、カード、文字の順を基本にします。
曲線・折れ線が必要な場合も、画像ではなく編集可能な線で作ります。

## 6. 内容を増やさない

専用指示書の「掲載文言」を確定文章として使用します。見出し階層、語順、否定、条件を守ります。
「制作意図」「配置」「禁止事項」「検収」は制作者向けで、スライドに転載しません。
実績値、料金、ベンチマーク、成功率、出典のない参考文献を追加しません。
設計説明や目標を「達成済み」「全件正常」「完全自律」へ変えません。
内部IP、VM番号、内部ホスト名、認証情報、実メール、個人・顧客情報、非公開リポジトリの情報を追加しません。
過去の文脈を今回の追加権限として扱う説明にしません。

## 7. 収まりが悪い場合の調整順

1. 誤った余白・不要な段落間隔を直し、専用指示書の改行を使います。
2. 同じ領域内でテキストボックスの幅・高さを調整し、見出しと本文を分離します。
3. 図形の幅、カード間隔、コネクタの経路を小幅に調整します。
4. 専用指示書に省略可能と明記された装飾だけを省きます。明記がない掲載文言は削除しません。
5. それでも不足する場合は、読みやすさを偽らず、残る問題を短く報告します。

禁止・留保の削除、極端な圧縮、文字の22pt未満への縮小、2枚への分割、画像化は解決策にしません。

## 8. 提出前の検査

構造：`.pptx`が実在し、スライドが1枚、16:9、編集可能な図形・文字であること。
文章：掲載文言の欠落・重複がなく、禁止条件と未確認の留保が残っていること。
書式：白背景、Meiryo UI指定、本文22pt以上、正しいページ番号であること。
図：矢印の接続先・向き・線種が指定どおりで、線が文字を横切らないこと。
描画：可能なら生成ファイルを描画して、切れ・重なり・はみ出し・不自然な改行を目視確認し、必要な修正を行うこと。
描画環境や実フォントがない場合は、構造の確認と見た目の未確認を区別します。確認していない検査を合格扱いにしません。

回答は実ファイルと短い確認結果だけで十分です。長い思考過程、制作計画、コードだけで納品を代用しません。
ファイル生成機能が使えない場合は、その制約を明示します。存在しないファイルやダウンロードリンクを作りません。
