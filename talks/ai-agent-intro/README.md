# AIエージェント入門（初心者向け）

AIエージェントが分からない人向けの、初心者向け資料2本です。どちらも全7枚です。

- [モデル編：AIエージェント入門](model.md) — ネモトロンというモデルを「友達」として紹介し、できること・できないこと、長所と短所を説明します。
- [スキル編：スキルとはなにか](skill.md) — スキルとは何かを説明します。モデルを変えずに「頼み方」を決める手順書であり、できないことは無理にお願いせず、長所を伸ばす書き方をする、という話です。

順番は、モデル編 → スキル編を想定しています。まず友達（モデル）の得意・不得意を知り、次にその友達への頼み方（スキル）を学びます。
