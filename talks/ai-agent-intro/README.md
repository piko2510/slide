# AIエージェント入門（初心者向け）

AIエージェントが分からない人向けの、初心者向け資料2本です。どちらも全7枚です。

- [モデル編：AIエージェント入門](model.md) — ネモトロンというモデルを「友達」として紹介し、できること・できないこと、長所と短所を説明します。
- [スキル編：スキルとはなにか](skill.md) — スキルとは何かを説明します。モデルを変えずに「頼み方」を決める手順書であり、できないことは無理にお願いせず、長所を伸ばす書き方をする、という話です。

順番は、モデル編 → スキル編を想定しています。まず友達（モデル）の得意・不得意を知り、次にその友達への頼み方（スキル）を学びます。

PowerPoint（PPTX）の原本はローカルにあり、このリポジトリには入れていません。このリポジトリでは、Markdownを掲載文言の正本として管理します。

## デザイン判断（デザイン基準 v7、2026-11刷新）

様式は固定せず、作る前に判断を宣言する。基準の正本は [制作仕様のデザイン基準 v7](../homelab-ai/production-spec.md) で、旧「5.6継承」（青固定・固定pt・角丸と影の全面禁止・全ページ同強度）は置き換え済み。2本とも、次を宣言して作る。

- 種類と読み手：初心者向けの説明資料。読み手はAIエージェントに身構える人。柔らかく、怖くないことが第一。業務テンプレにはしない。
- 色はデッキ一本を通して、背景を除いて3色まで。ページごとに持ち替えない。主色が視覚の60〜70％を占め、オレンジはできないこと・短所・注意の側だけに使う。
- モデル編：主色＝深いティール #2E8B57（淡色 #E4F1E9・濃色 #1F6B41 は同系統で1色）、アクセント＝温かいオレンジ #DE8326、中立色＝ #23201A 系、背景 #FFFBF8。
- スキル編：主色＝深いティール #0F6B5C（淡色 #DDECE7・#C2DCD4 は同系統で1色）、アクセント＝温かいオレンジ #C26714、中立色＝ #2B2B28 系、背景 #FDFBF7。
- モチーフ：モデル編は友達の吹き出し（「友達が自分のことを話す」形としてだけ使う）。スキル編は手順書のチェック線（チェックと番号の丸を主色の線でつなぐ）。チェック線は、それ自体が手順になるページ（2・5・7枚目）だけに置き、見出し帯として全ページに反復しない。
- 様式：各ページの主役は、主色のベタ面に白文字で作る。薄い色の面は従属の要素だけに使う。ページ型は使い回さない（対比のページ同士でも型を分ける）。締めの太字行は、台本（model.md / skill.md）で置くと宣言したページ（山場・まとめ）だけに置く。各ページの形は台本の「様式」が正本。
- 強弱：モデル編の山場は4枚目（長所と短所）、スキル編の山場は6枚目（頼み方の対比）。表紙は迎える強さ、中間のページは中、まとめは静かに。
- 配置は要素の関係が選ぶ。対比は左右2面、仕事の順序は横の流れ、場面と渡す先は対応表。均等なカードの羅列はしない。
- 残す規律：1枚1メッセージ。見出しは主張を言い切る文にする。主張と根拠は同じページに置く。無い数値は埋めない（数値は65k実測のみ）。文字の階層は大きさの対比で作り、固定pt表は置かない。本文の下限は18ptで、縮めて収めない。角丸は小さなものだけ可、影なし。
- 経路：ネイティブな編集可能図形のPPTX（python-pptx、フォントは Meiryo UI）。発表者ノートは全ページに付け、【話す内容】と【技術注記】に分ける。
