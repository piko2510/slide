# Copilot生成用デザイン指示｜AIエージェント入門（3本共通）

このファイルは、会社のCopilotで下記3本のPowerPointを生成するための、デザイン側の指示書です。
台本（script-model.md / script-skill.md / script-chat-agent.md）と対で使います。

- モデル編：Nemotronというモデルの特性（全9枚）
- スキル編：スキルとはなにか（全10枚）
- Chat型とAIエージェント編：2つの型の使い方の違い（全7枚）

## 使い方

1. 生成したい台本ファイルを1つ選び、このdesign.mdと一緒にCopilotへ添付します。
2. 台本ファイル冒頭の「Copilotへの指示文」を、チャット欄へ貼ります。
3. 出力は、台本に書かれた枚数どおりのPowerPointです。ページ番号は「N / 総枚数」です。
4. 別の台本の内容を混ぜないでください。デザインは3本ともこのdesign.mdが正本です。

デザインの基準は、このリポジトリの[デザイン基準 v7（2026-11刷新）](../../homelab-ai/production-spec.md)です。
旧「5.6継承」（青固定・固定pt・角丸と影の全面禁止・全ページ同強度）は置き換え済みであり、使わないでください。
以下は、v7のうちこの3本に適用する部分を、Copilotへの指示として書き直したものです。

## Copilotへの指示文（デザイン共通部）

台本と一緒に貼る場合は、台本側の指示文にこの共通部が含まれています。デザインだけを伝えるときは、次をそのまま貼ってください。

```text
添付の台本どおりに、PowerPointを作成してください。
デザインは次の宣言に従ってください。宣言していない様式を、既定のテーマや装飾で埋めないでください。

- 画面は16:9（13.333 × 7.5 inch）。フォントは Meiryo UI。英字・数字は Segoe UI。
- 色はデッキ一本を通して、背景を除いて3色までです。ページごとに持ち替えないでください。
主色＝深いティール #2E8B57（淡色 #E4F1E9・濃色 #1F6B41 は同系統で1色に数えます）。
アクセント＝温かいオレンジ #DE8326（淡色 #FBEEDC・濃色 #B96A14 は同系統）。できないこと・短所・注意・悪い例の側だけに使います。
中立色＝ #23201A 系（階調 #6F6A61／#D9D3C8／#EFEAE3 を含み1色に数えます）。文字・罫線・補足に使います。
背景は温かい白 #FFFBF8 で、3色には数えません。
- 主色が視覚の重さの60〜70％を占めます（淡色の面を含みます）。各ページの主役は、主色のベタ面に白文字で作ります。薄い色の面は従属の要素だけに使います。
- モチーフは「友達の吹き出し」（しっぽ付きの吹き出し形）1つをデッキに通します。「友達が自分のことを話す」意味を持つ形としてだけ使い、全ページの見出し帯のような装飾として反復しないでください。
- 1枚に1メッセージ。見出しは台本の文をそのまま使い、題名だけの名詞に変えないでください。主張と根拠（数値・図）は同じページに置きます。
- 文字の階層は大きさの対比で作ります。本文は18pt以上にし、収まらないときに文字を縮めないでください。文言を削るか、台本の指定どおりに配置を分けてください。
- 図はすべて編集可能なPowerPoint図形・コネクタ・テキストで作ります。画像の貼り付けで済ませないでください。角丸は小さなものだけ可、影は付けません。
- ストック写真、ロゴの透かし、空白を埋めるためだけの装飾、言葉の代わりに置く汎用アイコンは使わないでください。
- ページ番号は右下に「N / 総枚数」の書式で、全ページ統一します。
- 発表者ノートには、台本の「話す内容」と「技術注記」を、の見出しを付けてそのまま入れてください。台本全文を画面へ転載しないでください。
- 台本に無い数値・固有名詞・効果を足さないでください。
```

## この3本の宣言（デザイン基準 v7の「作る前に宣言する判断」）

### 種類と読み手

- 3本とも、AIエージェント初心者向けの説明資料。会社の勉強会での説明を想定します。
- 文体：モデル編とChat型とAIエージェント編は、です・ます調の硬い文章。スキル編は、優しい言葉の、です・ます調です。台本の文面を勝手に書き換えないでください。

### 色の役割

- 主色ティール #2E8B57：できること・長所・構造・主役の側。
- アクセントのオレンジ #DE8326：できないこと・短所・注意・悪い例の側だけ。同格にばらまかない。
- 中立色 #23201A 系：文字・罫線・補足と、「人」の側。
- 背景 #FFFBF8 は色に数えない。4色目を足したくなったら、色を増やさず、どれかの役割と入れ替える。

### ページの強弱

- モデル編：6枚目（長所と短所）が山場で最も強い。表紙は迎える強さ、他は中、9枚目（まとめ）は静か。
- スキル編：9枚目（頼み方の対比）が山場で最も強い。表紙は強い、他は中、10枚目（まとめ）は静か。
- Chat型とAIエージェント編：4枚目（対比）が山場。表紙は迎える強さ、他は中、7枚目（まとめ）は静か。
- 全ページを同じ強さにしない。対比のページが2枚以上あるときは、山場と通常ページでページ型を分ける。

### モチーフ

- 友達の吹き出し。項目をしっぽ付きの吹き出し形で示し、「友達が自分のことを話す」形として使います。
- モチーフは、それ自体がそのページの内容の構造になる所にだけ置きます。

### 要素の関係と配置

- 対比は左右2面（主役の側を広く）。順序・流れは横の流れ（役割の重さで幅を変え、均等にしない）。場面と渡す先は対応表。手順は吹き出しの並び順で示します。
- 均等なカードは、要素が本当に同格のときだけ使います。
- 配置の出発点（目安であり固定ではない）：見出しは x=0.55、y=0.38、w=12.23、h=0.85 inch付近。本文・図の領域は y=1.55 から h=4.75 程度。余白と基準線はデッキ全体でそろえます。
- 締めの太字行（ページ下部の結論文）は、台本で指定したページ（山場・まとめなど）だけに置き、全ページには付けません。

## 生成後の確認（Copilotの出力を受け取ったら見る点）

1. 枚数・順序・見出しが台本と一致し、ページ番号の書式と位置が全ページで統一されている。
2. 宣言した判断（色の役割と、デッキ全体で背景を除いて3色まで、ページの強弱、モチーフ）が、全ページで守られている。
3. AIっぽさの指紋が無い：全ページ同じ強さで山場が読めない、空白を装飾で埋めている、言葉を汎用アイコンへ置き換えている、見出しが名詞だけで主張が無い、主張と根拠が別ページに分かれている。
4. 見切れ、文節の境目でない不自然な改行（助詞1字が行頭に落ちる、単語の途中で割れる、1字だけの行）が無い。あれば幅か文言で直す。
5. 本文が18ptを割っていない。文字を縮めて収めたページが無い。
6. 各ページの発表者ノートに、台本の「話す内容」と「技術注記」が原文のまま分かれて入っている。
7. 台本に無い数値・固有名詞・効果が足されていない。
