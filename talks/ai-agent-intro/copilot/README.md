# Copilot生成セット｜AIエージェント入門（3本）

AIエージェント入門の3本を、会社のCopilotでPowerPointとして生成するためのセットです。
デザインの指示書1つと、デッキごとの台本3つで構成します。

```text
copilot/
├── design.md               3本共通のデザイン指示（デザイン基準 v7の、この3本への適用）
├── script-model.md         台本｜モデル編：Nemotronというモデルの特性（全9枚）
├── script-skill.md         台本｜スキル編：スキルとはなにか（全10枚）
└── script-chat-agent.md    台本｜Chat型とAIエージェント編：2つの型の使い方の違い（全7枚）
```

## 使い方

1. 作りたいデッキの台本ファイル（script-*.md）を1つ選びます。
2. design.md と、その台本ファイルの2つを、Copilotへ添付します。
3. 台本ファイル冒頭の「Copilotへの指示文」を、チャット欄へ貼ります。
4. 出力は、台本に書かれた枚数どおりのPowerPointです。ページ番号は「N / 総枚数」です。

別デッキの台本や、以前の版のファイルを混ぜないでください。
デザインは3本とも design.md が正本、掲載文言と発表者ノートは各台本が正本です。

デザイン基準そのものは[デザイン基準 v7（2026-11刷新）](../../homelab-ai/production-spec.md)に従います。
各デッキの掲載文言の正本は、親フォルダの台本（model.md / skill.md 等）側にもありますが、Copilot生成にはこのセットを使ってください。
