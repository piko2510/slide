# モデル編：AIエージェント入門プレゼンテーション

AIエージェント初心者向けに、ネモトロンというモデル／友達の性格・できること・長所と短所をやさしく説明する7枚の入門資料です。これはモデルの説明だけの資料で、スキルの説明は別資料（[スキル編](skill.md)）です。

デザイン判断（デザイン基準 v7）：主色は深いティール #2E8B57、オレンジ #DE8326 はできないこと・短所の側だけ、中立色 #23201A 系、背景 #FFFBF8。モチーフは友達の吹き出し。山場は4枚目（長所と短所）。表紙は迎える強さ、2・3・5・6枚目は中、7枚目は静かに。全体の宣言は [README](README.md) にある。

## 1. AIエージェントは友達、怖くないよ

表紙。モデルの説明 — ネモトロンという友達の話だよ。得意と不得意が分かれば、怖くなくなるよ。

## 2. できることと、できないことがあるよ

この資料はモデルの説明だよ。得意と不得意が分かれば、怖くなくなるよ。

- できること：大量のものから探して抜き出す、まとめて要約する、手順にそって手を動かす
- できないこと：最後の判断を下すこと、あいまいな頼み方を読み取ること、間違えないという保証

人と同じだよ。全部できる友達はいないし、全部できないわけでもないよ。

## 3. ネモトロンは、こんな友達だよ

小さくて、とにかく速い。目がよくて、探しものが得意。仕事場は、大量のログの中。「これを探して」に答えるのが役目だよ。

## 4. ネモトロンは、探すのは得意で、つなげて考えるのは苦手だよ

この資料の山場。長所と短所を左右2面で対比し、長所側を広く取る。

長所：

- 探す・抜き出すのが速い
- 突き合わせて、仕分けられる
- 要約して、一次振り分けができる
- 65kの長さでも、検索と抽出は保ったよ（実測）

短所：

- 資料をまたぐ推論は苦手
- 原因の連鎖は追いにくい
- 知らないものを、知っているものと間違えやすい
- 長い多段作業で、目的を見失いやすい

## 5. 得意が生きる仕事は、こんな仕事だよ

得意がそのまま生きる場面。順序は横の流れで見せる。

大量のログ → 探す → 抜き出して並べる → 仕分けて渡す → 人

- 探す：エラー時刻と該当行を見つける
- 抜き出して並べる：必要な情報だけを取り出して、比べられる形にする
- 仕分けて渡す：重さで分けて要約し、見るべきものから渡す
- 人：見るべきものから確認する

## 6. 苦手が出る場面では、人がそばにいるよ

苦手が出る場面では、無理をさせず、場面ごとに渡す先を分ける。

- 複数の資料をまたぐ判断 → 人や強いモデルへ渡す
- 原因の連鎖を追う仕事 → 人が最後まで見る
- 決まった形の解析 → コードに任せる

分からないものは、無理に答えず、分からないまま上げるよ。

## 7. まとめ

静かに閉じる。怖がらなくていいよ。得意と不得意を知れば、ネモトロンは、ちゃんと役に立つ友達になるよ。
